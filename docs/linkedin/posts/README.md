# posts/ — Índice de contenido LinkedIn

Fuente de verdad del pipeline de contenido. Publicación **siempre manual** del owner
(prohibida para agentes en este mandato).

## Estados

| Estado | Significado |
|---|---|
| `DRAFT` | Listo para revisión del owner; no publicado |
| `REVIEWED` | Owner aprobó el texto final |
| `PUBLISHED` | Publicado por el owner (registrar fecha + URL del post) |

## Borradores

| Archivo | Tema | Estado | Sugerencia de orden |
|---|---|---|---|
| `drafts/01-reposicionamiento.md` | Reposicionamiento profesional | DRAFT | 1º |
| `drafts/02-modernizacion-legacy.md` | Metodología de legacy modernization | DRAFT | 2º |
| `drafts/03-ia-aplicada-metodo.md` | IA generativa con método humano | DRAFT | 3º |
| `drafts/04-integraciones-fiscales.md` | Lecciones de integraciones fiscales LatAm | DRAFT | 4º |

## Reglas

1. Cadencia sugerida: 1 post cada 1–2 semanas; evaluar modo creador tras 2 meses sostenidos.
2. Tras publicar: actualizar estado en este índice + fijar post destacado como F-4 (`../FEATURED.md`).
3. Todo texto nuevo entra primero como borrador en `drafts/`; nada se publica sin pasar por aquí.
4. Hashtags: máximo 5, siempre relevantes al tema del post.
